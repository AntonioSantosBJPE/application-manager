Candidaturas: a lista principal, agrupada por status (fase 1).

- Arquétipo `ListPage`. Topbar com contagem, ordenação e "Nova candidatura" (`C`).
- Filtros: Ativas/Encerradas, nível, modelo e busca por empresa, título ou skill — todos na URL.
- Grupos por status (ordem do funil, do mais avançado ao menos), cada um com "+" para criar já naquele status.
- Linha: ícone de status, empresa (`body-strong`), título, duas skills, nível, modelo, cobertura do currículo (`4/6` obrigatórias em `mono`) e última atividade. Sugestão de "sem retorno?" em `warning` na própria linha.
- Clique abre o detalhe; status e nível mudam por menu de contexto sem sair da lista.
