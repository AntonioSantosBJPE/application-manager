Paleta de comandos ⌘K: buscar qualquer coisa, navegar e agir.

## Estrutura
- Diálogo de 600px, `surface-overlay`, `radius-lg`, `shadow-overlay`, a 120px do topo.
- Entrada de 48px em `heading-md` sem borda; grupos ("Ações", "Candidaturas", "Navegar") com título `caption` `text-muted`.
- Itens de 30px com ícone, texto e atalho/metadado à direita; item ativo em `surface-hover`.
- Rodapé `surface-raised` com as teclas de navegação.

## Regras
- Abre de qualquer tela com `⌘K` e pelo botão "Buscar" da sidebar.
- Busca candidaturas por empresa, título e skill; quando a busca não acha uma skill, oferece criá-la.
- Com um item em foco, as ações dele aparecem como grupo ("Mudar status…", "Adicionar nota").

Adição intencional: princípio "⌘K é a porta de entrada global".
