Uma skill do catálogo: obrigatória, desejável, privada ou coberta pelo currículo.

## Variantes
- Padrão (obrigatória): borda `border-strong`, texto `text`.
- `nice` (desejável): borda tracejada, texto `text-muted`.
- `private`: skill criada pela pessoa, ainda não promovida (marca "·"; no catálogo, selo "Privada").
- `match`: a skill aparece no currículo — fundo `accent-subtle`, texto `accent-text`, ícone `check`.
- Removível: "×" em `text-muted`. Adicionar: chip tracejado "+ Skill".

## Regras
- 22px, `radius-sm`, `caption`. Agrupadas em `.am-skills` com gap 4px.
- Nome oficial sempre ("Node.js"), nunca o apelido digitado.

Adição intencional: fatias Skill, Application e MasterResume.
