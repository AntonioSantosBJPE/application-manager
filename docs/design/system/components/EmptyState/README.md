Lista ou área vazia: uma frase e uma ação.

## Regras
- Caixa com borda tracejada `border-strong`, `radius-md`, alinhada à esquerda.
- Uma frase em `text-muted` dizendo o que vai aparecer ali e a ação primária que resolve.
- Sem ilustração, sem ícone grande.

Adição intencional: padrão "empty states sóbrios" dos princípios.
