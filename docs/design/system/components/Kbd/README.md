Tecla ou atalho de teclado, mostrado junto da ação.

## Regras
- `kbd` (Geist Mono 11px/500), 18px de altura, borda `border-strong`, fundo `surface-raised`.
- Dentro de botão primário herda `on-accent` com borda na mesma cor.
- Sequências ("G" "C") são duas teclas separadas; combinações usam os símbolos ⌘ ⇧ ⌥ ↵.

Adição intencional: princípio "teclado primeiro".
